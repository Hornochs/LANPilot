# Game notes

One file per game or game family with the facts that were **verified against a real server**:
ports, authentication, exact commands and form fields, quirks, and how to enable remote
control on the server side.

Files are added in the roadmap step that implements the game. Until then, see
[../research/remote-control-protocols.md](../research/remote-control-protocols.md) for the
unverified starting point.
